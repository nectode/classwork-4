# Ответы на контрольные вопросы: автозагрузка, абстрактные классы, свойства

**1. Когда PHP вызывает автозагрузчик и что будет, если файл класса не найден?**
В момент первого обращения к неизвестному классу (`new User()`, вызов статического метода, `extends`, `instanceof` и т. п.). PHP по очереди вызывает все функции, зарегистрированные через `spl_autoload_register()`. Если ни одна не подключила класс, возникает ошибка (`Class "..." not found`).

**2. Преимущество spl_autoload_register() перед __autoload()?**
`__autoload()` может быть только одна и удалена в PHP 8.0. `spl_autoload_register()` позволяет зарегистрировать несколько автозагрузчиков (стек), например свой и от Composer, они вызываются по очереди; можно использовать замыкания и методы классов.

**3. Чем абстрактный класс отличается от интерфейса? Когда что выбрать?**
Интерфейс описывает только сигнатуры методов (и константы), без реализации и обычных свойств; класс может реализовывать несколько интерфейсов. Абстрактный класс хранит и реализацию, и состояние (свойства), но наследоваться можно только от одного. Интерфейс выбирают для «контракта» между не связанными классами, абстрактный класс — для семейства похожих сущностей с общим кодом (как `Shape`, `Employee`).

**4. Можно ли создать объект абстрактного класса? Можно ли объявить абстрактное свойство?**
Объект создать нельзя (`new` даст ошибку), только объект наследника. Абстрактными в PHP могут быть только методы, свойства — нельзя; нужное свойство обеспечивают через абстрактные геттеры или конструктор абстрактного класса.

**5. Чем static-свойство отличается от обычного? Как обратиться?**
Статическое свойство принадлежит классу, а не объекту, и общее для всех экземпляров (например, счётчик). Внутри класса: `self::$count` (или `static::$count`), снаружи (если доступно): `ИмяКласса::$count`. Обычное свойство у каждого объекта своё: `$this->title`.

**6. Что делает readonly и какие ограничения?**
Свойство `readonly` (PHP 8.1+) можно инициализировать только один раз, обычно в конструкторе, и дальше оно только читается; попытка изменить даст `Error`. Ограничения: нужен тип свойства, значение по умолчанию задать нельзя, статическим свойство быть не может, присвоить значение можно только из области видимости класса.
